📖 Hướng dẫn cài đặt

1
Lấy Gemini API Key
Truy cập aistudio.google.com → Tạo API key mới → Copy và dán vào ô Gemini API Key.
2
Bật Google Sheets API
Vào console.cloud.google.com → APIs & Services → Enable APIs → tìm "Google Sheets API" → Enable.
3
Tạo Credentials
Cách đơn giản (API Key): APIs & Services → Credentials → Create Credentials → API Key.
Cách bảo mật hơn (OAuth): Create Credentials → OAuth 2.0 Client ID → Web application → Thêm http://localhost và URL hiện tại vào Authorized origins.
4
Lấy Sheet ID
Mở Google Sheets → Nhìn URL: https://docs.google.com/spreadsheets/d/[SHEET_ID]/edit → Copy phần in đậm.
5
Cấp quyền cho Sheet
Nếu dùng API Key: Mở Sheet → Share → Anyone with the link → Editor.
Nếu dùng OAuth: Đăng nhập Google là đủ.
